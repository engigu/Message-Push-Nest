# 更新日志

## 2026

### 2026.10.20 (v2.4.0)
- **数据清理全面放开至用户级与智能随机打散避峰**
  - 设置中心侧边栏「数据清理」由管理员专享放开至全员可用，普通用户可自主管理个人账号清理策略
  - 细粒度接口鉴权：普通用户仅限修改自身私有数据清理配置（`log_config` 与 `hosted_msg_config`），越权篡改站点级配置坚决返回 403 Forbidden
  - 数据层强隔离：任务日志与托管消息按 `created_by` 独立清理，彻底杜绝多租户相互误删；执行流水精确归属当前用户
  - 随机打散避峰调度：基于用户 ID 采用 FNV-1a 哈希算法将默认清理时间在凌晨低峰期（01:00 ~ 04:59，共 240 个槽位）自动均匀随机打散，前端提供「🎲 随机时间」快捷按钮，执行层加入 0~3 秒并发微抖动保护
- **演示模式安全防篡改与用户管理只读加固**
  - 用户管理页面展示醒目的演示模式告警横幅，新增用户、修改信息、重置密码、删除用户等操作全流程锁定置灰
  - 后端接口层硬拦截：所有用户写操作与密码修改在演示模式下一律返回 HTTP 403 Forbidden
- **多 SSO 身份源绑定与解绑**
  - 支持同一个本地账号绑定多个外部第三方身份源（如同时绑定企业 OIDC 与 GitHub/GitLab 等）
  - 账号中心可视化展示 SSO 绑定详情，并支持自助与管理员解绑
- **修复设置子 Tab 切换掉登录 Bug**
  - 修复公开路由白名单误判导致请求 SSO 接口未携带 `m-token` 返回 401 登出的缺陷（[#85](https://github.com/engigu/Message-Push-Nest/issues/85)）

### 2026.10.17 (v2.3.0)
- **OIDC 与通用 OAuth 2.0 单点登录 (SSO) 全面支持**
  - 标准 OIDC 通道：适配 Keycloak、Casdoor、Pocket ID、Authentik 等，支持根 Issuer 自动探测元数据、JWKS 签名校验与 PKCE (S256)
  - 通用 OAuth 2.0 通道：支持标准授权码模式，内置 GitHub、Gitee、GitLab 快捷一键预设
  - 支持多通道并行启用，登录页自适应展示可用单点登录方式
  - 支持“首次登录自动创建账号”开关与自动开通
  - 单点登录管理设置面板：支持连通性探测、参数校验与复制回调地址
  - 采用文本框+密文遮罩，彻底杜绝浏览器密码管理器对客户端密钥（Secret）的自动预填充
  - 全方位移动端与小屏自适应排版优化
- **新增统一提示页面 (Notice)**
  - 新增独立 `/notice` 页面并加入路由免登白名单，优雅提示 SSO 登录失败等状态，解决白屏黑屏
  - 提供错误详情、故障排查指引与一键返回重试
- **网络与代理自适应优化**
  - 登录与错误重定向全链路改为纯相对路径（`/#/notice` 与 `/#/?token=`）
  - Vite 开发代理通过 `configure` 钩子动态透传真实 Host 与协议，无缝适配反向代理
- **数据仪表盘动效与指标卡增强**
  - 移除整体生硬的页面与卡片淡入淡出（fade-in）位移动画，交互更灵敏
  - 折线图节点采用平滑由小到大的浮动入场动效，并彻底修复图例 marker 被裁剪为 1/4 圆的问题
  - 饼图采用连贯的一整圈平滑展开入场动效，告别离散割裂感
  - 新增「发送渠道数」统计卡片，并将指标卡片升级为 6 列自适应网格排版
- **前端分包构建与加载性能优化**
  - 独立拆分 `vendor-charts` 图表包（ApexCharts 独立打块），数据仪表盘业务包体积缩减 98%（557 kB 降至 9.58 kB），加快页面按需加载
  - 过滤 Rolldown `INVALID_ANNOTATION` 无效注释告警，保持构建输出干净整洁
- **前后端空值防御与依赖安全加固**
  - 升级 `github.com/getkin/kin-openapi` 至 `v0.151.0`，修复 6 个 CVE 安全漏洞
  - 定时消息服务空数据时初始化切片，避免 JSON 序列化返回 `null`
  - 前端多个列表页面（定时消息、发送任务、发送渠道等）全链路加入空值防御（`?.` 与 `|| []`），杜绝空数据状态下 `reading 'length'` 报错
- **演示模式智能感知与安全加固**
  - 支持通过访问域名（自动匹配 `demo` 域名）、URL 参数（`?demo=1` / `?mode=demo`）及环境变量智能激活演示模式
  - 登录表单自动预填 `admin` / `123456`，新增呼吸灯状态条与「一键填入」操作
  - 前端重置密码组件与后端密码修改接口双重防御，禁止演示模式下篡改管理员密码
